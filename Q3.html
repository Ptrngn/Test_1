The World Wide Web: Then and Now

Original Research at CERN

In 1989, Tim Berners-Lee created the World Wide Web at CERN. He made it so physicists could easily share their research with each other using linked pages.

The Current Uses of the Web

Today, people use the web for shopping, social media, videos, school, and talking to friends and family.

Comparing Then and Now

The web still uses the same basic tools it started with: HTML, links, and web addresses. The difference is that it was first made for a small group of scientists, and now billions of people use it every day.
